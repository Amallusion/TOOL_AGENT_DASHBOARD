# Deep-Sea Mining Alternatives

A visual map of companies, labs and projects that replace, reduce or recover the minerals deep-sea mining is after. Built by RAIC Team 21 for The Ocean Opportunity Lab, through the QS Responsible AI Consortium.

## About the data

A snapshot of the Team 21 discovery agent's run on 26 June 2026: 39 candidates found in public web sources, each awaiting expert review. This is not an official TOOL website, and listings are not endorsements.

## Optional images

The TOOL logo is already built into the page. Add any of these to an `assets` folder and the site picks them up automatically:

- `assets/tool-logo.png` to replace the logo with a higher-resolution official file
- `assets/ocean.jpg` for the page background photo
- `assets/banner.jpg` for the banner photo

If you use photos from a free library such as Unsplash, credit the photographer here.
